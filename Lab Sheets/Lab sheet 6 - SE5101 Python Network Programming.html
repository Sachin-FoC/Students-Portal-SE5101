3. Background: Why Python for Networking?

Python is widely used in security work because it is quick to write, readable, and ships with a powerful standard library. Its socket module gives direct access to the same TCP/UDP mechanisms you observed in Wireshark (Lab 04) and probed with Nmap (Lab 05) - but now you write the code that opens connections and sends data.

A socket is one endpoint of a two-way communication link between two programs over a network. It is identified by an IP address and a port number. The typical flow for a TCP connection is:

Server sideClient side
1. socket() - create socket1. socket() - create socket
2. bind() - attach to an IP/port 
3. listen() - wait for connections 
4. accept() - accept a client2. connect() - connect to server
5. recv() / send() - exchange data3. send() / recv() - exchange data
6. close()4. close()

6. Part C - TCP Client/Server with Sockets

6Build a TCP Echo Server

An echo server sends back whatever the client sends it. Create server.py:

import socket

HOST = "127.0.0.1"   # listen on localhost
PORT = 5000          # a free, non-privileged port

# 1. Create a TCP socket
server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Allow quick reuse of the address after restart
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

# 2. Bind to the IP/port and 3. listen
server_socket.bind((HOST, PORT))
server_socket.listen(1)
print(f"[*] Server listening on {HOST}:{PORT}")

# 4. Accept a client connection
conn, addr = server_socket.accept()
print(f"[+] Connection from {addr}")

# 5. Receive and echo data back
while True:
    data = conn.recv(1024)
    if not data:
        break
    print("[<] Received:", data.decode())
    conn.sendall(data)   # echo it back

conn.close()
server_socket.close()
print("[*] Connection closed")
What the arguments mean: AF_INET = IPv4, SOCK_STREAM = TCP. recv(1024) reads up to 1024 bytes. Data on a socket is bytes, so we .decode() to read it as text and the client will .encode() to send text.

7. Part D - Handling Multiple Clients with Threading

The server in Task 6 handles only one client at a time - it blocks inside accept() and the receive loop. To serve many clients at once, we give each accepted connection its own thread, so the main loop can go straight back to accepting new clients.

A thread is a separate line of execution running inside the same program. Python's threading module lets us start a new thread per client.

9Multi-Client Threaded Server

Create threaded_server.py:

import socket
import threading

HOST = "127.0.0.1"
PORT = 5000

def handle_client(conn, addr):
    """Runs in its own thread for each connected client."""
    print(f"[+] New connection from {addr}")
    while True:
        data = conn.recv(1024)
        if not data:
            break
        message = data.decode()
        print(f"[<] {addr}: {message}")
        reply = f"Server received: {message}"
        conn.sendall(reply.encode())
    conn.close()
    print(f"[-] {addr} disconnected")

def main():
    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind((HOST, PORT))
    server.listen(5)
    print(f"[*] Threaded server listening on {HOST}:{PORT}")

    while True:
        conn, addr = server.accept()
        # Hand this client to a new thread
        thread = threading.Thread(target=handle_client, args=(conn, addr))
        thread.start()
        print(f"[*] Active connections: {threading.active_count() - 1}")

if __name__ == "__main__":
    main()
Tip: listen(5) sets the backlog (how many pending connections may queue). Each call to threading.Thread(...).start() launches handle_client concurrently, so the while loop immediately returns to accept() for the next client.

11A Quick UDP Client/Server

UDP is connectionless - no handshake, no guaranteed delivery. Note the different socket type (SOCK_DGRAM) and that there is no listen()/accept().

udp_server.py:

import socket

server = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
server.bind(("127.0.0.1", 6000))
print("[*] UDP server ready on port 6000")

while True:
    data, addr = server.recvfrom(1024)
    print(f"[<] From {addr}: {data.decode()}")
    server.sendto(b"ACK: " + data, addr)

udp_client.py:

import socket

client = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
msg = input("Message to send over UDP: ")
client.sendto(msg.encode(), ("127.0.0.1", 6000))

data, addr = client.recvfrom(1024)
print("[>] Reply:", data.decode())
client.close()

12Build a Basic Port Scanner (links to Lab 05)

This ties your Python skills back to the Nmap lab: you'll write a tiny TCP connect scanner. It tries to connect to a range of ports and reports which are open.

import socket

def scan_port(host, port):
    """Return True if the TCP port is open, else False."""
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.5)          # don't wait forever
    result = s.connect_ex((host, port))   # 0 means success
    s.close()
    return result == 0

target = "127.0.0.1"
print(f"[*] Scanning {target} ...")

for port in range(1, 1025):
    if scan_port(target, port):
        print(f"[+] Port {port} is OPEN")

print("[*] Scan complete")
